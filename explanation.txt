This EC2 User Data script is a Bash script that runs automatically the first time an EC2 instance boots, and it begins with the shebang #!/bin/bash, which tells the operating system to execute the script using the Bash shell. The script then updates the instance using yum update -y, ensuring all installed packages are current and secure without requiring manual confirmation. Next, it installs the Apache web server with yum install -y httpd, which provides the software needed to serve web pages over HTTP. The commands systemctl enable httpd and systemctl start httpd configure Apache to start automatically on every reboot and also start it immediately so the web server is available right away. The script then uses a here-document with cat << 'EOF' > /var/www/html/index.html to write the entire HTML website directly into Apache’s default web root, ensuring the page is served automatically when the instance’s public IP is accessed. The quoted EOF ensures that the HTML and JavaScript content are written exactly as intended without variable substitution. Once the file is created, chown apache:apache /var/www/html/index.html sets the ownership of the webpage to the Apache user, which prevents permission-related issues, and chmod 644 /var/www/html/index.html assigns read permissions to the web server and the public while allowing only the owner to modify the file. As a result, when the EC2 instance finishes launching, Apache is fully configured, the website is in place, and the static webpage is immediately accessible without any additional manual setup.
